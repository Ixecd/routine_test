# FPGA vs MCU：最小系统的差异——多出来的"配置电路"

> 2026-09-07
> 从 FG202(GW1N) 看电路图时沉淀：MCU 最小系统的骨架知识能直接迁移到 FPGA，唯 FPGA 多一环 MCU 没有的"配置电路"。

## 一、最小系统构成对照

```
MCU 最小系统：  本体 + 电源 + 复位电路 + 晶振
                （程序在片内 flash，上电自启，天经地义）

FPGA 最小系统： 本体 + 电源 + 复位 + 晶振 + 【配置电路】
                                        ↑ 这一坨 MCU 完全没有
```

## 二、逐项差异

### 电源：一样在，但 FPGA 更讲究
```
MCU：一般 3.3V（+VDDA 模拟）
FPGA：内核 VCCINT + IO bank VCCIO（可多组、可不同电压）
      + 可能 VCCAUX / PLL 电压；上电有时序要求
→ 轨更多，去耦更密（上电瞬态电流大）
```

### 晶振：几乎一比一
```
MCU：晶振供系统时钟
FPGA：外部时钟进专用时钟引脚（FG202 的 50MHz 在 IO98，不是随便一个 IO）
```

### 复位：这里开始分岔
```
MCU：NRST + RC/复位芯片 → 复位后从片内 flash 向量启动跑固件
FPGA：没有"复位后跑程序"——
  上电后是"空的"，得先被灌进 bitstream 才变成要的逻辑
  → FPGA 的"复位"对应物 = 配置层复位(RECONFIG_N) + 启动过程
  → 用户逻辑内部的 reset 是设计里的事，不属于硬件最小系统
```

### 配置电路：FPGA 独有，是灵魂
```
根因：FPGA 是 SRAM 工艺 → 上电丢配置
MCU  把"程序存储 + 启动"集成片内 → 上电自启，感觉不到它的存在
FPGA 每次上电都不知道"自己是谁"，必须从外部装进来：
  · 配置存储：外部 SPI Flash(W25Q32) 或片内小 flash
  · 启动模式：MODE 引脚（从哪 boot）
  · 下载口：JTAG（怎么灌）
  → FG202 上那坨 W25Q32 + MODE 电阻 + JTAG 就是它
```

## 三、一句话类比

> FPGA 像一个每次上电都失忆的 MCU——
> MCU 上电记得自己是谁（片内固件）；
> FPGA 上电不知道自己是谁，得靠外部把"你是谁"重新喂给它。
> 所以 FPGA 最小系统 = MCU 最小系统 + 一整套"喂记忆"的配置电路。

## 四、读 FPGA 板图（如 FG202）的速记

```
① 电源/晶振  → MCU 经验直接认
② "复位电路" → 脑补成"配置/启动电路"（RECONFIG_N / MODE / DONE / READY）
③ W25Q32 + MODE 电阻 + JTAG  → 就是"喂记忆"那套，别当普通外设看
```
